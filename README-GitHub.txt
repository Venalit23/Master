СВОЁ ДЕЛО — ЮЛИЙ СЕМИЧОВ
Обновление: обращение по электронной почте и открытие страницы с начала.

КАК ОБНОВИТЬ
1. Распакуйте архив.
2. Откройте существующий репозиторий Venalit23/Master на GitHub.
3. Через Upload files загрузите index.html и contact.vcf из этого архива
   в корень репозитория, заменив прежние файлы. Нажмите Commit changes.
4. Дождитесь завершения обновления GitHub Pages и обновите сайт в браузере.

Имена файлов должны быть точно index.html и contact.vcf — без цифр,
скобок и дополнительных расширений. Новый репозиторий создавать не нужно.
Настройки GitHub Pages менять не нужно.

САЙТ
https://venalit23.github.io/Master/

QR-КОД
Существующий QR со ссылкой https://venalit23.github.io/Master/#request
можно оставить: после обновления файла index.html новый вход по этой
ссылке откроет страницу сверху. Для новых ссылок используйте адрес без #request.

ПРОВЕРКА ПОСЛЕ ОБНОВЛЕНИЯ
1. Откройте сайт в новой вкладке по старой QR-ссылке с #request.
   Страница должна начинаться с первого экрана.
2. Нажмите «Подготовить запрос» у нужной услуги и отредактируйте текст.
3. Нажмите «Отправить на почту». Проверьте получателя, тему и текст
   в открывшемся черновике. Для проверки отправлять письмо не требуется.
4. Нажмите «Добавить контакт»: в карточке должны быть оба телефона и почта.

Для проверки используйте опубликованный сайт в Safari или другом браузере,
а не встроенный предпросмотр локального HTML-файла.
